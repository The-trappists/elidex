| 2026-11-07 | Patterns count a problem told in other words as the same problem: same place, plus two guards that nothing overrules (contradicting symptom checks; a workaround vs its cure, checked across whole groups), plus similar words, identical checks, or, with `EMBEDDING_MODEL`, cosine similarity ≥ `PATTERNS_SAME_MEANING` (cached vectors, words only if the model fails). | 2026-11-07 | The loop is fully automated: knowledge goes live with no human review, and no specialist is ever asked for a click, a confirmation or a rating. | 2026-11-07 | Linking stays deterministic (`link.py`: exact IDs, aliases, class from type, model and install years, abstain when unsure). LLM agents sit only where the text is ambiguous. | 2026-11-07 | Keep the pipeline (listen, understand, link, store, reconcile) and add three targeted agents: a critic inside understand (second model checks each item against its quote), a reconcile judge after store (supports, contradicts, supersedes, unrelated against neighbours) and a passive outcome loop (the agent's applied action is posted in a thread, the technician's reply updates trust).
